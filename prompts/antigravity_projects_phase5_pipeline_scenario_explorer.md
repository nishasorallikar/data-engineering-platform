# STEP 7 — SCENARIO FLOW

The flow should connect the selected scenario to the architecture.

Example conceptual flow:

```text
SCENARIO
   ↓
RELEVANT ARCHITECTURE LAYER
   ↓
DOCUMENTED HANDLING
   ↓
NEXT DOCUMENTED LAYER / DESTINATION
```

However:

IMPORTANT:

Do NOT invent connections simply because a scenario belongs to Bronze, Silver, or Gold.

Only draw a path when the source data supports the relationship.

If the dataset only documents:

```text
Layer:
Silver

Handling:
<documented handling>
```

then the visualization should not pretend that the source explicitly documents:

```text
Source → Event Hubs → Bronze → Silver → Gold → Power BI
```

unless that relationship is supported.

# STEP 8 — ALWAYS-ON SCENARIO MOTION

The scenario explorer should teach through motion.

When a scenario is selected:

```text

      ↓

      ↓
documented flow
```

Use subtle continuous motion.

Possible visual language:

```text
● → ● → ●
```

or:

```text
───────────────→
 animated flow
```

Motion should communicate progression.

Do NOT require clicking repeatedly to understand the flow.

- deterministic
- subtle
- continuous while active
- isolated from Fundamental 50
- isolated from InteractionRegistry

